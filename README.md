# SimpleMusicTuner

Тюнер для гитары и других инструментов. Звук с микрофона (`AudioRecord`, 44,1 кГц) проходит через окно Ханна и FFT, написанный руками в `FFTHelper`. Пик уточняется параболической интерполяцией, потом частота переводится в ноту и отклонение в центах от A4 = 440 Гц.

Шум отсекается по RMS и по тому, насколько пик выше среднего по спектру. Частота показывается, только если держится несколько замеров подряд. Чувствительность настраивается ползунком, для гитары в стандартном строе тюнер подписывает номер струны.

Compose, ViewModel, StateFlow, настройки в DataStore.
